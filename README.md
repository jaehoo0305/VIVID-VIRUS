# Vivid Virus
[게임 다운로드](https://drive.google.com/drive/folders/1D3Afwf74gpejaY54-WzrIk44uqBOLQB4)

**Vivid Virus**는 인체 내부를 무대로, 바이러스가 세포를 감염하며 성장하는 과정을 플레이어가 직접 체험하는 **감염 캐주얼 게임**입니다.  
기존 전염병 시뮬레이션(Plague Inc.)이 세계 단위 확산을 다루는 반면, 본 게임은 **세포 단위 전투**와 **면역 시스템 회피**에 초점을 맞춥니다.

---

## 주요 특징 (Features)
- **세포 단위 감염**: 수용체 인식, 세포막 등 실제 바이러스 감염 과정을 반영
- **면역 회피 시스템**: 백혈구·대식세포 등 인체 면역을 상대하며 잠복·회피

---

## 🖥️ 설치 및 실행 (Installation)
### 요구사항
- Unity 2021.3 이상  
- Android 지원
